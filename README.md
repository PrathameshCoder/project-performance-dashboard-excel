# Project Performance Dashboard – Excel

## Overview
A self-initiated project management dashboard built in Microsoft Excel to demonstrate budget tracking, forecasting, KPI analysis, schedule monitoring and RAG status reporting.

## Features
- Budget vs Actual Cost analysis
- Budget vs Forecast Cost analysis
- Planned vs Actual Progress tracking
- Budget and schedule variance analysis
- KPI summary cards
- Open risk tracking
- RAG status indicators
- Management insights

## Tools
Microsoft Excel:
- Formulas
- Charts
- Conditional Formatting
- KPI Dashboard Design

## Example Insights
- Total Budget: €65,000
- Forecast Cost: €66,800
- Forecast Overrun: €1,800
- Overall Project Progress: 46%
